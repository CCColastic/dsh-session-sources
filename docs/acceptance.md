# 会话资料验收记录

目标宿主：DSH Desktop **0.2.1-rc.5**。实现使用公开插件机制，不修改 DSH 核心。

## 自动验证

- 构建及 JavaScript 语法检查通过，中英文语言键一致。
- **30 项自动测试通过**：历史重建、checkpoint 尾部重放、会话隔离、分支继承、附件去重、多来源保留、用户消息过滤、Markdown/裸链接解析、缺失原件、鉴权、流式读取，以及可管理 Tab 注册和卸载。
- 新增 4 项客户端适配测试覆盖 `registerTab` 元数据、开始页唯一入口、原生入口回退、A/B 会话投影与输入框隔离。
- 真实 Windows Host 集成检查覆盖原生图片/文件保存与读取、会话投影、跨会话隔离、分支继承、历史重建、缺失附件隔离和未认证请求拒绝；机器结果为 [host-smoke.json](host-smoke.json)。

| 功能 | 状态 |
| --- | --- |

## 验证说明

自动测试和 Host 集成检查不等同于完整 GUI 验收。不同宿主版本、主题、下载落盘、剪贴板和输入框呈现仍应在实际 DSH 窗口中检查。工具浏览器未持有 Desktop 登录态时，不能把 HTTP 401 环境当作界面验收结果。

主聊天原生消息跳转需要宿主提供可从前述入口调用的公开导航接口；当前“查看来源”面板是明确披露的替代交互。
